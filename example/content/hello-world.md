# Why I Built Pagesmith

Most static site generators pull in a whole ecosystem. Pagesmith is one
Python file and the standard library.

## What it supports

- **Headings**, *emphasis*, and `inline code`
- Code blocks, lists, blockquotes, links, and images
- Front matter for titles and dates
- An RSS feed, generated automatically

> Simplicity is a feature.

Try `python cli.py serve --reload` and edit this file — the browser updates
itself.
